# habit-tracker-and-productivity-monitor-51006-53241

## Running the Backend on Port 3001

To start the backend FastAPI server (will always run on port 3001):

```bash
cd habit_tracker_backend
bash start.sh
```

Or, make it executable and run directly:
```bash
chmod +x start.sh
./start.sh
```

The API will be accessible at [http://localhost:3001](http://localhost:3001)
